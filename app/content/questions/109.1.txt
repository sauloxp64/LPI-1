### 109.1-017 | unica | 2
ref: 102:p.404, 102:p.407
tags: ttl
Qual é a função do campo TTL (Time To Live) do cabeçalho de um pacote IPv4?
= Limitar os saltos: cada roteador o diminui e, ao chegar a 0, o pacote é descartado
- Informar por quantos segundos o endereço de origem fica válido na tabela ARP do destino
- Definir quantas vezes o TCP tentará retransmitir o pacote antes de desistir da conexão
- Indicar o tamanho máximo, em bytes, que o pacote pode ter antes de ser fragmentado
> O TTL é um contador que a origem define e cada roteador (salto) decrementa. Se chegar a zero, o pacote é descartado, o que evita que pacotes circulem para sempre em laços de roteamento (e é o princípio de funcionamento do `traceroute`).
> As outras opções descrevem outros mecanismos: cache ARP, retransmissão do TCP e MTU/fragmentação.

### 109.1-038 | unica | 2
ref: 102:p.412
tags: ipv6, anycast
Qual descrição corresponde a um endereço IPv6 do tipo anycast?
= Identifica um conjunto de interfaces, mas o pacote é entregue a apenas uma delas
- Identifica um conjunto de interfaces e o pacote é entregue a todas ao mesmo tempo
- Identifica uma única interface de rede e o pacote é entregue somente a essa interface
- Identifica todas as interfaces da rede local e substitui o broadcast do IPv4
> No anycast vários nós compartilham o mesmo endereço, mas o pacote é entregue a apenas um deles. Entregar a todas as interfaces do conjunto é o multicast; entregar a uma única interface é o unicast; e a função de "todos os nós do enlace" é atendida pelo multicast `ff02::1`.

### 109.1-039 | unica | 3
ref: 102:p.412
tags: ipv6, multicast, broadcast
O IPv6 não tem broadcast. Qual endereço é usado para alcançar todos os hosts do enlace local, de modo semelhante ao broadcast do IPv4?
= ff02::1
- fe80::1
- ff00::/8
- ff02::2
> `ff02::1` é o multicast "todos os nós" do enlace local (equivalente prático a `224.0.0.1` no IPv4).
> `fe80::1` é um endereço unicast link-local de uma interface; `ff00::/8` é o prefixo que contém todos os endereços multicast, não um endereço de grupo; `ff02::2` é o multicast "todos os roteadores".

Como se indica a porta 443 ao acessar o host IPv6 `2001:db8::10` em uma notação de endereço e porta?
= [2001:db8::10]:443

- [2001:db8::10:443]
- [2001:db8::10]:[443]

### 109.1-042 | unica | 2
ref: 102:p.413
tags: ipv6, hop limit
Qual campo do cabeçalho IPv6 substitui o TTL do IPv4?
= Hop Limit
- Flow Label
- Next Header
- Payload Length
> O Hop Limit (limite de saltos) tem a mesma função do TTL: é decrementado a cada roteador e o pacote é descartado ao chegar a zero. Flow Label, Next Header e Payload Length são outros campos do cabeçalho IPv6, com funções distintas.

### 109.1-043 | unica | 2
ref: 102:p.413
tags: ipv6, ndp, arp
Qual protocolo do IPv6 exerce papel semelhante ao do ARP no IPv4 e descobre também vizinhos, roteadores e prefixos?
= NDP (Neighbor Discovery Protocol)
- SLAAC (Stateless Address Autoconfiguration)
- DHCPv6 (Dynamic Host Configuration Protocol)
- IGMP (Internet Group Management Protocol)
> O NDP substitui o ARP no IPv6 e oferece mais recursos (descoberta de vizinhos, de roteadores, de endereços duplicados, etc.).
> O SLAAC é o mecanismo de autoconfiguração de endereços (que se apoia no NDP); DHCPv6 é um protocolo de atribuição de configuração por servidor; IGMP gerencia grupos multicast no IPv4.

### 109.1-044 | multipla | 3

tags: ipv6, ipv4, diferenças
Quais afirmações sobre as diferenças entre IPv4 e IPv6 estão corretas?
= O IPv6 não tem broadcast; para alcançar todos os hosts do enlace usa-se multicast
= Os hosts IPv6 podem se autoconfigurar por SLAAC, sem servidor DHCP
= O TTL do IPv4 foi substituído pelo Hop Limit no cabeçalho do IPv6
